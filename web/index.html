    System Maintenance

    Perform system maintenance tasks like restarting the application or rebooting the Raspberry Pi.

    Tip: For automatic restart functionality, run ChitUI using sudo ./run.sh instead of running main.py directly.
    Restart Application

    Restart the ChitUI application. This will reload all plugins and apply any configuration changes. The web interface will reconnect automatically.

    Reboot Raspberry Pi

    Reboot the entire Raspberry Pi system. This will disconnect all printers and stop the application. Wait about 30-60 seconds before reconnecting.

    Note: Both operations will temporarily interrupt your connection to the system.

    Version 2.3.0
    What's New in 2.3.0

    Theme System 2.3.0 update

    • UI Themes — a full theme system in Settings → Appearance. Themes are pure CSS skins installed as ZIPs into data/themes/ (one folder per theme), with preview images, click-to-enlarge previews, one-click apply and delete. Switching back to the built-in ChitUI Default Theme is always one click away, and the login and change-password pages are themed too.
    • Light & Dark per theme — every theme card has a Light / Dark selector, applied together with the theme. The choice is stored on the server and survives reboots.
    • Theme Designer — a visual editor (desktop browsers) with live preview against the real stylesheet: drag & drop layout re-arranging (sections, columns, sidebar side), per-mode color palettes, solid / gradient / image backgrounds, icon swapping, and export as an installable ZIP or direct one-click install. Fully offline-capable.
    • Theme development kit — a downloadable starter template with a documented light + dark scaffold, plus a complete theming guide (THEMING.md) covering styling, assets, and moving / resizing / re-arranging interface elements with pure CSS.
    • Theme updates & safety — re-uploading a theme with the same id updates it in place; uploads are validated (manifest, size limits, unsafe paths rejected) and installed atomically; themes cannot contain executable code, only static assets.

    New Features

    • Plugin Store — browse, install and update plugins directly from within ChitUI. Plugins are downloaded server-side (no CORS issues), dependencies are installed automatically, and a live terminal shows progress during install.
    • Plugin update notifications — ChitUI checks for plugin updates at startup and every 24 hours. A banner appears when new versions are available, with a direct link to the Plugin Store.
    • Plugin Store caching — the store catalog is cached for 5 minutes and pre-loaded in the background, so the Plugin Store opens instantly after the first check.
    • Fast plugin startup — dependency checks now use importlib to detect already-installed packages before invoking pip, reducing boot time significantly.
    • Install progress terminal — clicking Install in the Plugin Store shows a live terminal window with pip output, a clear success or failure result, and a Restart reminder.

    Bug Fixes

    • Fixed Plugin Store button closing the Settings modal without opening the store.
    • Fixed aria-hidden="true" on Plugin Store modal preventing it from ever opening.
    • Fixed syntax error in Content-Disposition regex causing the entire Plugin Store IIFE to silently fail.
    • Fixed CORS error when installing plugins — downloads are now proxied through the Pi server.
    • Fixed spurious WARNING: Plugin web has no plugin.json log entry on every boot.

    About This Project

    ChitUI is an enhanced web-based interface for controlling Chitu-based resin 3D printers. It provides real-time monitoring, file management via USB gadget mode, UART serial support, an extensible plugin system, and a built-in Plugin Store for one-click plugin installs and updates.

    • Automatic printer discovery via UDP broadcast
    • Real-time status monitoring via WebSocket
    • File upload & management (USB Gadget, Network & UART modes)
    • Thumbnail extraction from .ctb and .goo files
    • Print control — start, pause, resume, stop
    • Temperature monitoring and control
    • Multi-printer support BETA
    • Plugin Store — browse, install & update plugins from chitui.net
    • Background plugin update checks with banner notifications
    • User authentication and session management

    Install New Plugin
    How to install a plugin
    1. Obtain a plugin .zip file from the plugin author.
    2. The ZIP must contain a single top-level folder with plugin.json and __init__.py.
    3. If the plugin has Python dependencies they must be listed in requirements.txt or in plugin.json under "dependencies" – they will be installed automatically.
    4. After installation is complete, reboot the server to activate the plugin.
    Only .zip files are accepted.
